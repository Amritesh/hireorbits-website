# Hireorbits Website Implementation Plan

> Execute inline using the executing-plans workflow. Design and publication are approved.

**Goal:** Build the approved company website and publish it to Amritesh's GitHub Pages.

**Architecture:** Astro produces static pages from small shared components and service data. A single stylesheet controls the visual system; navigation is the only client script. Hosting parameters are environment variables so the output can move to another host.

**Tech Stack:** Astro, local Manrope font, CSS, Node's built-in test runner, GitHub Actions.

## Tasks

- [ ] Scaffold package/config, ignore private source documents, and add a production-output smoke test. Run `node --test tests/site.test.mjs` before building to establish the missing-output failure.
- [ ] Create `src/data/company.ts` for capabilities, industries, delivery models, and navigation; keep copy sourced from the supplied document.
- [ ] Create `src/layouts/Layout.astro` and components for icons, header, footer, page headings, service cards, and consultation CTA. Use a base-aware URL helper for every internal link.
- [ ] Build `src/pages/index.astro`: large typographic introduction with orbital accent, services, industries, company introduction, delivery models, and contact CTA.
- [ ] Build the thirteen supporting pages. Use native disclosures for detailed services, mailto contact/application actions, honest editorial empty states, and factual site notices.
- [ ] Add `src/styles/global.css` for mobile-first layouts, visible focus, native readable spacing, reduced motion, and desktop/mobile navigation.
- [ ] Run `npm run build && npm test`. The test checks required pages, link and asset resolution, one heading per page, and absence of placeholder contact data.
- [ ] Inspect actual desktop and mobile pages in the browser. Exercise menus, disclosures, nested routes, and contact links. Fix any observed issues and repeat affected checks.
- [ ] Add README instructions for development, content edits, and moving hosting; configure GitHub Actions with build/test/upload/deploy.
- [ ] Review diff and tracked files, create the repository under Amritesh, enable Pages, push, and verify deployment and public pages. Record the exact live URL.

## Acceptance

Every requested page exists. Source documents stay local. All capabilities are represented without invented credentials, clients, jobs, or results. CSS and assets work under `/hireorbits-website/` and at `/` when rebuilt. No backend or fake submission success is shipped.
